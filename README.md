## 关于这个仓库

2026 级计算机专业本科生，广东。大一开学前开始自学 C++，跟着教程一个项目一个项目敲过来，全部代码手写在 Visual Studio 里。

- **学习周期**：2026-06-25 → 2026-09-02
- **项目数量**：42 个独立可编译的 VS 工程
- **代码规模**：1183 行（40 个源文件）
- **最大项目**：通讯录管理系统（294 行，综合运用了结构体、数组、函数、流程控制）

每个目录都是一个完整的 Visual Studio 工程（`.slnx` + `.vcxproj`），打开即可编译运行。

仓库只保留源码和工程配置，所有 `.exe`、`.obj`、`.vs` 缓存等编译产物已通过 `.gitignore` 排除。

## 如何运行

**方式一：Visual Studio（推荐）**

用 VS 2022 或更高版本打开任意目录下的 `.slnx` 文件，按 `F5` 编译运行。

**方式二：命令行**

```bash
g++ 文件名.cpp -o 文件名.exe
./文件名.exe
```
